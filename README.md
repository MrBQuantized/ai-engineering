## How to use this repo

Each numbered top-level folder is a track. Inside each track, subfolders group notes, code, and experiments by subtopic, and a `projects/` folder holds track-specific mini-projects. `07_PROJECTS/` is reserved for larger, end-to-end builds that pull together skills from multiple tracks.

`.gitkeep` files are placeholders so the empty folder structure is preserved in git — delete one as soon as you add real content to that folder.
