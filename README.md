# 🤖 AI Engineering

A practical learning repository for building the foundations of **AI Engineering**, from Large Language Models and RAG to agents, production AI systems, AI infrastructure, and eventually Edge AI.

This repository focuses on **understanding concepts, building projects, and applying them to real systems** rather than collecting frameworks or following tutorials indefinitely.

> **Learn → Build → Evaluate → Apply → Iterate**

---

## 🎯 Goals

* Understand modern AI systems beyond simply calling an API
* Build applications powered by Large Language Models
* Learn Retrieval-Augmented Generation (RAG)
* Build tool-using and agentic AI systems
* Learn AI evaluation, observability, and security
* Understand how AI systems are deployed and operated in production
* Develop foundations for AI infrastructure and Edge AI
* Apply concepts to real-world projects

Building AI systems that can retrieve external knowledge.

* Embeddings
* Chunking

* Vector databases

### 03 — Agents

Building AI systems capable of reasoning through tasks and using tools.

## 🧪 Learning Philosophy

This repository is not intended to be a collection of copied tutorials.

Each major topic follows a practical cycle:

```text
Concept
   ↓
Study
   ↓
Small Experiment
   ↓
Build
   ↓
Evaluate
   ↓
Improve
   ↓
Real-World Application
```

The goal is to understand **why systems work**, not just memorize framework APIs.
